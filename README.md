**ETS2 Coaches Ceske Hlasky z OMSI CZ**

Plugin přidává do Euro Truck Simulator 2 – Coaches české reakce cestujících z dabingu OMSI. Cestující se ozvou při prudkém brzdění a zatáčení, výrazných nerovnostech, pokutách, kolizích a poklesu spokojenosti za jízdy.

**Požadavky**

Euro Truck Simulator 2 s DLC Coaches

Windows, 64bitová verze hry

**Instalace**

V sekci Releases rozklikni nejnovější verzi a v části Assets stáhni ETS2_Coaches_OMSI_CZ_Plugin.zip.

Vypni ETS2 a rozbal ZIP. Soubory CoachesOmSiCZ.dll a CoachesOmSiCZ.ini zkopíruj do složky Euro Truck Simulator 2\bin\win_x64\plugins. Pokud složka plugins chybí, vytvoř ji.
Hlasitost a citlivost reakcí upravíš v CoachesOmSiCZ.ini
